# Prompt Codex — Task 7: Admin MVP

Crie um admin simples para pedidos.

Leia:

- `docs/10-ADMIN.md`
- `docs/09-BANCO-DE-DADOS.md`

Entregáveis:

- `/admin` protegido por senha via `ADMIN_PASSWORD`.
- Lista de pedidos mockados ou reais, dependendo da estrutura já criada.
- Detalhe do pedido.
- Alteração de status.
- Visualização de personalizações.
- Campo de rastreio.

Regras:

- Não criar permissões complexas.
- Não expor arquivos pessoais publicamente.
- Não incluir dados sensíveis em logs.
