# 00 — Contexto do Projeto

## O que estamos criando

Um portal profissional standalone para a Galanta Medical, tendo Galanta Ortho como linha inicial de desenvolvimento para órteses e imobilizadores 3D.

O projeto migra da referência provisória de ecommerce B2C para uma plataforma B2B/B2B2C voltada a profissionais de saúde, clínicas, hospitais e pontos de atendimento. A conversão inicial será uma solicitação técnica qualificada, sem compra aberta enquanto as decisões comerciais e regulatórias não estiverem concluídas.

## Decisões já tomadas

```txt
Marca principal: Galanta Medical
Linha inicial: Galanta Ortho
Categoria de desenvolvimento: Órteses e imobilizadores 3D
Produto/modelo específico: A confirmar
Domínio local: http://localhost:3000
Gateway futuro previsto: Pagar.me, condicionado ao modelo comercial
Base44: Não usar
Stack: Next.js + TypeScript + Tailwind
Desenvolvimento: Codex + GitHub
Deploy: Docker em servidor próprio
Banco sugerido: Supabase/PostgreSQL
Storage sugerido: Supabase Storage, S3 ou Cloudflare R2
```

## Referência provisória anterior

A referência Eternize serviu para criar o scaffold inicial, mas não deve orientar a nova identidade, copy, catálogo ou fluxo comercial. Componentes e fundações técnicas existentes podem ser reaproveitados quando forem neutros e adequados ao domínio Galanta.

## O que deve orientar a evolução

- linguagem clínica, técnica e profissional;
- conceito visual Clinical Tech Industrial;
- modelo Standard + Personal;
- disponibilidade, adaptação e personalização;
- solicitação de apresentação, amostra, proposta ou planejamento de estoque;
- compliance e ausência de claims não validados;
- arquitetura configurável para receber detalhes técnicos posteriormente.

## O que NÃO deve ser mantido

- nome, copy e estética Eternize;
- categorias de presentes e personalização afetiva;
- preço ou condição comercial inventada;
- indicação, finalidade, material, protocolo ou benefício clínico não fornecido;
- afirmações de aprovação, regularização ou liberação de uso;
- venda direta antes das decisões aplicáveis.

## Objetivo comercial

Criar uma plataforma profissional preparada para apresentar a Galanta Ortho, qualificar interesse B2B, construir autoridade técnica e evoluir para operação comercial quando produto e regras estiverem definidos.

O site deve ser:

- Rápido.
- Visualmente consistente com a Galanta Medical.
- Responsivo.
- Premium.
- Fácil de entender e de solicitar contato técnico.
- Fácil de editar.
- Preparado para linhas Standard e Personal.
- Preparado para solicitação profissional qualificada.
- Preparado para uma integração futura com Pagar.me, sem dependência no MVP B2B.
- Preparado para escalar em múltiplas categorias.

## Filosofia do projeto

Primeiro criar uma base profissional, confiável e configurável. Depois evoluir produto, operação, painel, automações e integrações a partir das informações aprovadas.

Não começar pelo complexo. Começar pelo que comunica, qualifica e pode ser validado com segurança.
