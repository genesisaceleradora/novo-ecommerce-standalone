# Prompt Codex — Task 4: Carrinho

Implemente carrinho lateral persistente.

Entregáveis:

- `CartDrawer`.
- Estado do carrinho com Context ou Zustand.
- Persistência em `localStorage`.
- Adicionar produto.
- Remover produto.
- Alterar quantidade.
- Subtotal.
- Resumo da personalização quando existir.
- Botão para checkout.

Regras:

- Carrinho mobile deve ser fácil de usar.
- Não implementar pagamento nesta task.
- Não perder dados de personalização no carrinho.
