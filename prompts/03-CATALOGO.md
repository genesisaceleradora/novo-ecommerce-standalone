# Prompt Codex — Task 3: Catálogo

Crie a estrutura de catálogo com dados mockados.

Leia:

- `docs/05-PRODUTOS-E-CATEGORIAS.md`
- `seed/categories.example.json`
- `seed/products.example.json`

Entregáveis:

- Tipos `Category`, `Product`, `ProductImage`, `PersonalizationConfig`.
- Dados mockados em `/src/data`.
- Página `/categoria/[slug]`.
- Página `/produto/[slug]`.
- Cards de produto.
- Produtos relacionados simples.

Regras:

- Não tratar dados mockados como finais.
- Não inventar produto principal final.
- Categoria inexistente deve retornar 404.
